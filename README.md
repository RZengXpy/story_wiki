# StoryForge — AI Screenwriter Studio

AI 辅助小说转剧本工具，基于多 Agent 架构与 Story Graph 知识表示，将小说文本自动转换为结构化、可编辑的 YAML 剧本。

## 依赖

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| openai | >= 1.10.0 | LLM API 调用 |
| streamlit | >= 1.30.0 | Web 界面 |
| pyyaml | >= 6.0.1 | YAML 序列化 |
| pytest | >= 8.0.0 | 单元测试 |
| pytest-asyncio | >= 0.23.0 | 异步测试支持 |
